# k-flouris.github.io

Source for https://k-flouris.github.io (built by GitHub Pages with Jekyll).

- Page content: `index.html`, `publications.html`, `talks.html`, `teaching.html`, `awards.html` (each starts with a short front-matter block).
- Shared parts, edited once for all pages: `_includes/sidebar.html` (photo, title, links), `_includes/masthead.html` (top menu), `_includes/footer.html`.
- Page skeleton: `_layouts/default.html`. Styles: `style.css`.
